# AGENTS.md

Agents working in this repository must read [VISION.md](VISION.md) before making product, architecture, scope, or backlog-disposition decisions.
VISION.md is the acceptance policy for this project: use it to judge whether a proposed change, issue, or PR fits.
This file intentionally does not duplicate user-global or tool-level instructions.

## Boston publication window

- Repository reads, edits, and validation may run anytime. Do not create commits, push, open/update PRs, or publish/release on weekdays from 09:00 inclusive until 18:00 exclusive in Boston local time (`America/New_York`, DST-aware EST/EDT), unless the user explicitly authorizes an exception in the current session. Weekends and weekdays at/after 18:00 or before 09:00 are allowed.
